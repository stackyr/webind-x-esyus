# Webind × Esyus

A high-performance cinematic digital agency experience crafted with Next.js, Tailwind CSS, Motion, and canvas-driven sequential rendering.

## 🚀 Features

- **Continuous Cinematic Canvas Sequence**: Smooth hardware-accelerated 240-frame sequence scrolling with zero layout shift.
- **Dynamic Mobile App Experience**: Dedicated bottom dock navigation with haptic micro-interactions for mobile viewports.
- **Interactive Multi-Step Project Inquiry**: 7-step guided questionnaire with instant real-time quote generation and email inquiries.
- **Seamless Infinite Brand Marquee**: Dual-row reverse continuous ticker with pro frosted glass design.
- **Scroll-Expanding Video Showcase**: Fluid scroll-driven full-screen video transitions with audio toggle.
- **Living Liquid Molten Glow Footer**: Animated multi-layer plasma liquid waves and glowing shimmers.

## 🛠 Tech Stack

- **Framework**: [Next.js](https://nextjs.org/) (App Router)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **Animations**: [Motion / Framer Motion](https://motion.dev/)
- **Icons**: [Lucide React](https://lucide.dev/)

## 📦 Getting Started

Install dependencies:
```bash
npm install
```

Start development server:
```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the application.
